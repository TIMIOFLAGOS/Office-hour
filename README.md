# OfficeHour 

**OfficeHour** is a streamlined, web-based appointment booking platform designed specifically for individual lecturers to manage student consultations efficiently. It eliminates the friction of manual scheduling, back-and-forth emails, and missed office hours.

---

##  Features
* **Availability Management:** Lecturers can set and update their open consultation slots.
* **Student Booking Portal:** Students can easily view open times and book appointments in a few clicks.
* **Purpose Tracking:** Students can specify the meeting agenda/topic before booking so the lecturer can prepare.
* **Automated Status Updates:** Track upcoming, completed, or cancelled sessions.

---

## Tech Stack
* **Frontend:** React.js / Tailwind CSS *(Update if using HTML/CSS modules)*
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / Mongoose
* **Authentication:** JSON Web Tokens (JWT) / bcrypt
